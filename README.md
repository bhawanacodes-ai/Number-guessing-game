 Number Guessing Game

A simple and interactive Number Guessing Game developed using Python and Tkinter. The game provides a graphical user interface (GUI) where players try to guess a randomly generated number.

 Project Description

The Number Guessing Game is a beginner-friendly Python project designed to make guessing a number more fun and interactive through a graphical interface.

The computer randomly selects a secret number within a specified range. The player enters a guess, and the game provides hints such as "Too High", "Too Low", or "Correct!".

The project demonstrates the use of Python programming concepts along with GUI development using Tkinter.

 Features

-  Interactive graphical interface
-  Random number generation
-  High/Low hints
-  Limited attempts
-  Winning message
-  Play Again option
-  Exit option
-  Displays remaining attempts
-  Simple and user-friendly interface

 How to Run
1. Install Python

Make sure Python 3 is installed on your computer.

2. Download or Clone the Repository

git clone https://github.com/your-username/Number-Guessing-Game.git

3. Open the Project Folder

cd Number-Guessing-Game

4. Run the Program

python number_guessing_game.py

The game window will open automatically.

 How to Play

1. Start the game.
2. Enter a number in the input box.
3. Click the Guess button.
4. Check the hint provided by the game.
5. Continue guessing until you find the secret number.
6. Use Play Again to start a new game.

 Objective

The main objective of this project is to develop a simple game while learning how Python programming concepts can be combined with Tkinter GUI development.
